Step-by-Step

1. Login

  • Open the app in your browser
  • Enter your username & password
  • Same page for all roles

2. Request Break (Operator)

  • Go to Scan page
  • Tap "Request Break"
  • Scan the QR code at break area

3. Approve (Supervisor)

  • See pending request on Dashboard
  • Set break duration
  • Click Approve or Reject

4. During Break

  • Timer starts automatically
  • 5-minute reminder before end
  • Status shows "On Break"

5. End Break (Operator)

  • Return to break area
  • Scan QR code again
  • Or tap "End Break" on Dashboard

6. Reports

  • View daily break stats
  • Check late returns
  • Export staff summaries
Pro Tip: You can also request and end breaks directly from the Dashboard without scanning a QR code. The QR just makes it faster!
